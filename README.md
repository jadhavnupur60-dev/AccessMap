# ACCES (AccessMap) 🗺️♿

ACCES (AccessMap) is a web-based accessibility mapping system designed to help users locate, review, and report accessibility features of various facilities and public spaces. Built with **Flask**, **SQLAlchemy**, and **SQLite**, the application empowers communities to build inclusive environments by sharing real-time accessibility data.

---

## ✨ Features & Modules

* **Facility Management**: Browse, search, and add public locations, buildings, and community spaces with detailed location data.
* **Accessibility Reviews**: Rate and review facilities based on specific accessibility criteria (e.g., wheelchair ramps, elevators, braille signage, and accessible parking).
* **Issue Reporting**: Report accessibility barriers or maintenance issues (such as broken lifts or blocked pathways) to notify others and local administrators.
* **Interactive Frontend**: Clean, responsive UI built using HTML5, CSS3, and modular JavaScript.
* **Database Management**: Relational data management powered by Flask-SQLAlchemy and SQLite with utility scripts for database inspection (`show_db.py`).

---

## 🛠️ Tech Stack

* **Backend**: Python, Flask, Flask-SQLAlchemy
* **Database**: SQLite
* **Frontend**: HTML5, CSS3, JavaScript
* **Version Control**: Git & GitHub
